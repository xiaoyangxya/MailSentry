# 信哨 / MailSentry

MailSentry is under active development.

## Repository contents

- Application source and project documentation
- Project-level agent instructions and workflow configuration

Local configuration, secrets, dependencies, build output, caches, and generated test artifacts are excluded from version control.

## Optional development skills

The project-level agent skills used during development are installed locally and are not committed to this repository. They can be installed when needed with:

`powershell
npx skills@latest add mattpocock/skills --agent codex --yes
`
